Lazy Load New Tabs

Open links in a new tab with lazy loading.

Core Controls
Enable Lazy Load Tabs Turn lazy loading on or off.
Auto Load Lazy Tabs Load tabs automatically after a delay.
Group Lazy Tabs Keep lazy tabs grouped per window.
Cooling Period
One lazy tab loads per interval.
Lower values load faster, higher values reduce CPU spikes.
Keyboard Shortcut
Open hovered link as lazy tab Hover a link, then press the shortcut.
Default: Alt+Shift+L (Windows), Command+Shift+L (Mac). Chrome manages shortcuts.
Queued Lazy Tabs 0
    No queued lazy tabs.
    Site Exceptions
    Matches a domain and its subdomains.
